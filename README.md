# Python Utility Module

This project contains a reusable Python module with common utility functions. The module is designed to reduce repeated code by providing simple functions for validation, text formatting, calculations, date handling, and file operations.

The project includes two files. `utils.py` contains all utility functions and `main.py` demonstrates how to use them.

Functions included:

`is_num()` checks whether a value is numeric.

`cap()` formats text using title case.

`add()`, `sub()`, `mul()`, and `div()` perform basic arithmetic.

`exists()` checks if a file is available.

`read()` reads the contents of a file.

`write()` creates or updates a text file.

`today()` returns the current date.

Run the project with:

`python main.py`

Requirements:

Python 3.x
